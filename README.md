# Streamlit Water Quality Dashboard
### Purpose
Interactive Streamlit app to explore water quality data from Biscayne Bay, including temperature, 
salinity, and depth. Users can visualize and filter the data to see patterns and trends.
### Dataset
biscayneBay_waterquality.csv
### Features
Descriptive Statistics, 2D and 3D Plots, and the NASA Astronomy Picture of the Day
### Usage
In terminal, run "streamlit run dashboard.py"
